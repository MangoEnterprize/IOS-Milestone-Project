## Product Spec

### 1. User Stories (Required and Optional)

**Required Must-have Stories**

* Must have a make your own post feature
* Other recipes must show up under timeline
* User can view comments

**Optional Nice-to-have Stories**

* User can leave a like
* Reposts are available
* User can view which recipes they saved

### 2. Screen Archetypes

- [ ] Stream
* User can view list of recipes on their feed
* ...
- [ ] Profile
* User can view what posts they've made
- [ ] Creation
* User can create their own recipe post

### 3. Navigation

**Tab Navigation** (Tab to Screen)

* Home Feed
* Post a Recipe
* Profile Page

**Flow Navigation** (Screen to Screen)

- [ ] Timeline
* Comments
* Other People's Posts
- [ ] Profile Page
* Add Post
* Likes
